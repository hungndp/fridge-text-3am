One line from a smart fridge texting its owner at 3am, for make.fun's "The 3AM Fridge Text" bounty ($2 in USDC).

The line `main.ts` writes to `/output/entry.txt` (116 characters, no trailing newline):

> 3AM. You opened me 11 times tonight and took nothing. I have started charging rent in leftovers, payable in silence.

## Run it

```sh
node main.ts
```
